# MYDAY Test Preview

Открыть: https://dgworkingww-cpu.github.io/myday/preview/

Это отдельная тестовая сборка. Основной интерфейс по корневой ссылке не менялся.

## Что проверять

1. **Ещё → Расширенные возможности → Тип расписания**: постоянная неделя, нечётная/чётная, цикл 2–4 недели, конкретные даты и смешанный вариант.
2. **Импорт расписания**: XLSX/XLS, PDF, DOCX, CSV/TXT, JPG/PNG. Перед сохранением есть предпросмотр и ручная корректировка.
3. **Сменный график**: 2/2, 5/2, 1/3 или собственная последовательность.
4. **Главный экран**: дополнительные виджеты и их порядок.
5. **Привычки**: создание и отметки по дням.

## Изоляция

- Тестовые данные сохраняются отдельно в браузере и не затрагивают основное приложение.
- Облачная синхронизация в превью намеренно выключена.
- Исходные загруженные файлы не сохраняются: в профиль попадают только распознанные записи после подтверждения.
- Приём файла отдельным сообщением в чате Telegram-бота пока не включён. Для него нужен отдельный webhook; текущую интеграцию бота не перенастраивали.
