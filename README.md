# MYDAY

Мобильный планировщик и органайзер, который работает как Telegram Mini App и PWA.

## Структура

- `index.html` — интерфейс и прикладная логика MYDAY.
- `design-system.css` — единая адаптивная дизайн-система, светлая и тёмная темы.
- `backend-config.js` — публичная конфигурация Supabase (URL и publishable key; секреты сюда не помещать).
- `supabase/functions/myday-sync` — серверная синхронизация профилей с проверкой подписи Telegram.\n- `supabase/functions/myday-bot` — диалоговый Telegram-бот: задачи из текста, голосовых сообщений и фотографий, команды и быстрые действия.
- `supabase/migrations` — схема профилей и защита версий при конкурентных изменениях.
- `manifest.webmanifest`, `sw.js`, иконки — установка PWA и офлайн-оболочка.

## Хранение и синхронизация

Приложение хранит локальную копию профиля в браузере для быстрого запуска и устойчивости к временной потере сети. При запуске через Telegram Mini App профиль синхронизируется с Supabase через Edge Function, которая проверяет подписанные Telegram initData. Секрет Telegram-бота и ключ service role хранятся только в секретах GitHub Actions / Supabase и не должны попадать в клиентский код.

Пользовательские данные включают расписание, задачи, учебные предметы, события, заметки и настройки. Бот и Mini App работают с одним профилем; описание возможностей и настройки webhook находятся в `docs/MYDAY_TELEGRAM_ASSISTANT.md` и `SUPABASE_SETUP.md`. Для резервного копирования доступны экспорт и импорт JSON внутри раздела «Ещё».

## Установка на iPhone

Откройте production-сайт в Safari, выберите «Поделиться» → «На экран Домой». В Telegram откройте бота MYDAY и используйте кнопку меню. Интерфейс адаптирован для Telegram WebView, Safari и установленной PWA.

Service worker кэширует оболочку приложения для офлайн-запуска. Облачная синхронизация требует подключения к интернету. Браузер и iOS могут приостанавливать таймеры в фоне, поэтому локальные напоминания не гарантируются после закрытия приложения.

## Разработка и деплой

Изменения фронтенда публикуются через GitHub Pages. Изменения Supabase schema/functions проходят workflow `.github/workflows/deploy-myday-backend.yml`. Перед изменениями данных сохраняйте совместимость с существующими профилями и API-контрактами.
