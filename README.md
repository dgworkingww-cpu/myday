# MYDAY — Персональный учебный органайзер

PWA для студента. Тёмная деловая тема, локальное хранение, офлайн.

## Быстрый просмотр

Откройте файл **index.html** в браузере — всё работает сразу.

## Установка на iPhone

1. Включите GitHub Pages (см. ниже).
2. Откройте сайт в **Safari**.
3. Поделиться → **На экран «Домой»**.

## Включить GitHub Pages

1. Зайди в репозиторий → **Settings** → **Pages**
2. Source: **Deploy from a branch**
3. Branch: **main** / **/(root)** → Save
4. Через минуту появится ссылка: `https://dgworkingww-cpu.github.io/myday/`

## Возможности

- Расписание с авто-чередованием чётной/нечётной недели (контрольная дата 16.11.2026 — нечётная)
- Удобный список домашних заданий с фильтрами по предметам
- Раздел «Мои данные» (сайты, логины без паролей, ссылки, заметки)
- Экспорт / импорт JSON
- Полностью локально, без серверов и регистрации

## Цвета

Тёмно-фиолетовый деловой акцент (#8B5CF6), глубокий тёмный фон.

Пароли в приложении не хранятся — используйте менеджер паролей iOS.
