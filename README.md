# MYDAY 2.0

Мобильное приложение для расписания, задач и учёбы. Это статический PWA-пакет без сборки и платных API.

## В комплекте

- `index.html` — приложение и сохранённые в исходном MYDAY функции/данные расписания.
- `manifest.webmanifest`, `sw.js`, `icon.svg`, `icon-180.png` — установка и офлайн-оболочка.
- Данные остаются в локальном хранилище браузера; сервер не получает задачи, логин или вложения.

## Перенос данных из исходного файла

Хранилище браузера может быть привязано к отдельному адресу, поэтому версия в этой папке не всегда увидит данные исходного файла автоматически.

1. Откройте исходный `MYDAY.html` и перейдите в **Ещё → Скачать резервную копию**.
2. Разместите эту папку на HTTPS-сайте или откройте через локальный веб-сервер.
3. В новой версии выберите **Ещё → Импорт JSON** и укажите скачанный файл.

Исходный файл из папки «Загрузки» не изменён.

## Установка на iPhone

PWA требует HTTPS. Откройте страницу в Safari, нажмите **Поделиться → На экран «Домой»** и запустите добавленное приложение хотя бы один раз онлайн. После этого интерфейс и файлы оболочки доступны офлайн; для синхронизации между устройствами сервер не настроен.

Уведомления используют разрешение браузера и таймер приложения. iOS может приостанавливать таймер в фоне; закрытое приложение не получает расписание напоминаний. Надёжная доставка в фоне потребовала бы отдельного Web Push сервера, который не входит в этот пакет.

## Данные и приватность

Экспорт создаёт JSON-файл для резервного копирования. Импорт проверяет формат и типы вложений до замены текущих данных. Пароли не запрашиваются и не сохраняются. Небольшие вложения (до 512 КБ) помещаются в локальное хранилище; крупные документы лучше хранить в файлах iPhone и добавить ссылку в описание задания.
