# MYDAY 2.0 — Atelier

Полный визуальный язык, не продолжение стеклянных карточек прошлой версии.

## Концепция

Личный дневник дня: тёплая бумага, чернильная типографика, один хвойный акцент. Дата — крупный заголовок Literata, интерфейс — Manrope. Иерархия строится размером и пустым местом, а не стопкой одинаковых карточек.

Светлая тема: фон `#efeae2`, поверхность `#fbf8f3`, текст `#1c1915`.
Тёмная тема проектируется отдельно: `#12110f` / `#1d1b18` / `#f4efe6`, акцент светлеет, чтобы не кричать.

## Навигация

Пять вкладок у большого пальца: Сегодня, План, Задачи, Учёба, Ещё. Плавающая панель с заливкой, не стеклянный герой. Календарь, неделя, статистика, университет и заметки живут в «Ещё», чтобы первый экран отвечал только на вопрос «что сегодня».

## Что не менялось

Профиль, расписание, задачи, задания, Telegram initData, Supabase sync, экспорт и импорт. Серверная схема и Edge Function не переписывались.
